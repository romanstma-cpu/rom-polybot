ROM PolyBot 2.36.7 fixes a crash on the Evidence screen. Reopening or refreshing Evidence within five minutes of an earlier visit returned the execution-shadow report in the wrong shape, and the whole window was replaced by the reload screen. The report now has the same shape on every call. A failure in any single page is also contained to that page: the sidebar, title bar and emergency stop stay usable, and Try again reloads the page.

The app starts faster. Overview and onboarding load first; other pages and the charting library load on first visit and are prefetched while the app is idle, so switching pages stays instant. The startup renderer bundle is about a quarter of its previous size. On a new install without saved API keys, the balance check now logs a setup hint instead of a warning, and the last 10-pixel labels are now 11 pixels.

Every Electron end-to-end suite now runs before a Windows release, and a test that began failing once its recorded date passed the 60-day retention window has been fixed. Trading logic, entry gates, sizing and risk limits are unchanged. No live orders were sent during validation, and this release does not establish profitable trading.
