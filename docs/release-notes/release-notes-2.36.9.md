ROM PolyBot 2.36.9 fixes a crash on the Evidence screen. Reopening or refreshing Evidence within five minutes of an earlier visit returned the execution-shadow report in the wrong shape, and the whole window was replaced by the reload screen. The report now has the same shape on every call, and a failure in any single page is contained to that page: the sidebar, title bar and emergency stop stay usable, and Try again reloads the page. A window last saved on a monitor that has since been disconnected now reopens on screen instead of out of reach.

The app starts faster. Overview and onboarding load first; other pages and the charting library load on first visit and are prefetched while the app is idle. The packaged renderer now enforces a Content-Security-Policy that refuses inline scripts and other origins. On a new install without saved API keys, the balance check logs a setup hint instead of a warning, and the last 10-pixel labels are now 11 pixels.

Every Electron end-to-end suite now runs before a Windows release. Trading logic, entry gates, sizing and risk limits are unchanged. No live orders were sent during validation, and this release does not establish profitable trading. Versions 2.36.7 and 2.36.8 were built but not published.
